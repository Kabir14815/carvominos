# Carvaminos

React app. Run `npm run dev` and open http://localhost:5175/

## Where to look

```
src/
  main.jsx              # app start + router
  App.jsx               # all page routes
  data.js               # shared copy (FAQ, vehicles, steps)
  components/           # reusable UI blocks
    Navbar.jsx
    Footer.jsx
    Hero.jsx
    Logo.jsx
    ...one file per section
  pages/                # one file per website page
    Home.jsx
    Options.jsx
    Help.jsx
    Dealers.jsx
    Dealerships.jsx     # B2B Spanish leads
    About.jsx
    Contact.jsx
    Guides.jsx
public/
  carvaminos-logo.jpg
  cars/                 # vehicle photos
```
